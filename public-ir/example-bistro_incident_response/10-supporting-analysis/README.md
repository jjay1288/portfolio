# Supporting Analysis

This folder keeps the public-safe supporting analysis behind the final reports.

| File | Why It Is Included |
| --- | --- |
| `malicious-domain-research.md` | Shows infrastructure research, campaign clustering, abuse-reporting targets, and reasoning about attacker infrastructure. |
| `server-scan-findings.md` | Shows the live-host findings that drove containment and eradication decisions. |

Draft notes, one-off TODO files, raw archive listings, and bulk scan outputs were removed from the public version. Their conclusions are represented in the incident report, evidence inventory, IOC registry, and malware analysis documents.
